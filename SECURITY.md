# Security Policy

## About this project

This repository contains a **safe ransomware simulator** for security education and awareness training purposes. It does **not** contain real malware, real encryption logic, or any capability to cause harm to systems or data.

If you believe this project is being used maliciously or has been forked/modified to include harmful behavior, please contact us immediately.

---

## Reporting concerns

| Type | Action |
|------|--------|
| Misuse of this tool or a harmful fork | Email us (see below) |
| Suspected active abuse using this repo as a delivery vector | Email us **and** [report to GitHub](https://support.github.com/contact/report-abuse) |
| Suggestion to improve safety of the simulation | Open a GitHub Issue |

**Contact:** qu4n5ss@gmail.com

Please include:
- A description of the concern
- A link to the relevant repository or file (if applicable)
- Any evidence of misuse

We aim to respond within **48 hours**.

---

## Scope

This policy covers the original repository only. We are not responsible for forks or modified versions that may have introduced harmful behavior. If you find such a fork, please report it directly to GitHub.

---

## Out of scope

- False positive AV/EDR detections (expected behavior — see README)
- Feature requests (open a GitHub Issue instead)
